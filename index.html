02 / THE CONTROL PATH

Every explanation
has a chain of custody.

A plausible answer is insufficient. Sentinel applies explicit checks before releasing an attributed finding explanation.

  1. 01

    Preserve the observation

    Pr0jectZer0 supplies inventory and findings. MDF preserves records and their mapping history for scoped retrieval.

    SOURCE
  2. 02

    Verify the original bytes

    Check retrieved raw evidence against recorded hashes and exact mappings, within the authorized source and tenant.

    INTEGRITY
  3. 03

    Prove the relationship

    Reconcile endpoint identity, product, version, observation time and the specific finding. Withhold when the relationship fails.

    BOUNDARY
  4. 04

    Retain the decision

    Persist the result, evidence references and audit checkpoint. Reopen the session and verify it again after restart.

    TRACE

EXPLICIT ACTION / VISIBLE CONSEQUENCES

An operator starts the run.
A saved session keeps the record.

The configured Run Analysis action reports progress, supports cancellation and opens completed sessions. Local-model use is an explicit choice. The workflow analyzes preserved records; it does not automatically collect a new endpoint inventory.

Models work through typed controller boundaries. Remediation remains advisory; .NET guidance is attributed to Pr0jectZer0. The default execution path has no cloud dependency.

DEVELOPMENT EVIDENCE

Synthetic development cases across two endpoints, with two retained local-model configurations and three repetitions each. Labels are author-proposed.

THE FAILURE WORTH SHOWING

90 proposals blocked

In the bounded-schema run, the model proposed support on all 108 attempts. The gate blocked all 90 negative cases under the proposed labels. This supports the bounded gate—not model accuracy.
